# Equipo Desempleados - Análisis de Riesgo

Repo de equipo para el semestre de Otoño 2026 del curso de Análisis de Riesgo (ITESO).

## Integrantes

- Regina Tamayo
- Paulina Loera

## Qué incluye este repo

- `datos_historicos`: Carpeta de todos los datos usados durante el proyecto.
- `entregables`: Contiene los entregables del semestre.
- `graficas`: Todas las gráficas usadas en formato png.
- `src`: Carpeta que contiene el codigo detras de cada calculo, función, usado durante el proyecto.
- `modelos_varianza`: Contiene los modelos de varianza vistos en clase aplicados al activo (GMEXICOB).

## Referencias del proyecto

* de Lara Haro, A. (2018). *Medición y control de riesgos financieros*. Limusa.

* Venegas, F. (2008). *Riesgos financieros y económicos*. Cengage.
* Hull, J. C. (2022). *Options, futures and other derivatives*. Pearson.
